Core Objectives

부산 축제 가이드 서비스의 5가지 핵심 목표

1. 실시간 공공데이터 API 연동

공공데이터포털 부산광역시 축제 API 서비스키를 활용하여 부산 전역에서 실시간으로 개최되는 문화행사 및 대표 축제 데이터 수신.

2. 구·군 및 날짜 기반 세밀한 검색

부산 16개 구·군별 개별 필터, 개최 월별(1~12월) 필터, 사용자 지정 날짜(Date Range) 조회를 지원하여 원하는 시기와 장소를 즉시 필터링.

3. 인터랙티브 3대 뷰 모드

한눈에 보기 쉬운 카드 그리드, 월/일별 시각적 일정을 확인하는 달력, 부산 16개 구·군 핀을 직접 누르는 지도 뷰 제공.

4. Vercel & Express 서버리스 안정성

CORS 이슈 방지를 위해 Serverless Proxy를 두고, 공공 API 오류 시에도 고품질 16개 부산 대표 축제 Fallback 데이터로 자동 전환.

5. 관심 축제 저장 & 길찾기 공유

LocalStorage 기반 북마크 기능으로 재방문 시 저장 목록 유지. 카카오맵/네이버지도 길찾기 및 클립보드 공유 기능 탑재.

Key Features

주요 기능 명세 (Key Specifications)

01

축제 검색 & 세밀한 필터링

  • 지역 필터: 부산광역시 16개 구·군(해운대구, 수영구, 기장군 등) 전체 개별 선택
  • 월별 및 기간 필터: 1월 ~ 12월 월별 조회 및 시작/종료 지정 날짜 범위 검색
  • 카테고리/테마: 해양/해변, 불꽃/야경, 문화/예술, 영화/영상, 음식 등 8개 테마
  • 진행 상태 구분: 🟢 진행중 / 🔵 개최예정 / ⚪ 종료 상태 실시간 분류
02

3가지 인터랙티브 보기 모드

  • 카드 그리드 뷰 (Grid): 포스터 이미지, 상태 태그, 위치, 요금 및 북마크
  • 달력 뷰 (Calendar): 월별/일별 개최 축제 건수 및 타임라인 일정 확인
  • 부산 지도 뷰 (Map): 16개 구·군 핀 클릭을 통한 구역별 축제 즉시 필터링
03

축제 상세 정보 & 길찾기 연동

  • 상세 정보 제공: 개최 기간, 도로명 주소, 요금, 문의 전화, 프로그램 설명
  • 외부 지도 앱 연동: 카카오맵 / 네이버지도 원클릭 길찾기 이동
  • 스마트 공유: 축제 명칭 및 일정 정보 클립보드 복사 공유
04

관심 축제 저장 & Fallback 안정성

  • 로컬스토리지 저장: 별도 로그인 없이 관심 축제를 브라우저에 지속 보관
  • 자동 Fallback 시스템: 공공데이터 API 장애 발생 시 16개 대표 축제 데이터 자동 전환
  • CORS 프록시: Vercel Serverless `/api/festivals` 우회로 API 키 보안 유지
